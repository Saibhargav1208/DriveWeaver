╔════════════════════════════════════════════════════════════════════════════╗
║                   HOW IT FLOWS THROUGH THE MODEL                           ║
╚════════════════════════════════════════════════════════════════════════════╝

Input: history_slots [batch, 4, 11, 128]  ← From VideoSAUR
       vlm_guidance: {
         'old': [batch, 4, 256, 3584],     ← What VLM sees/understands
         'new': [batch, 4, 16, 3584]       ← What VLM predicts
       }

     ↓

┌────────────────────────────────────────────────────────────────────────┐
│  C-JEPA Predictor with VLM Guidance                                    │
└────────────────────────────────────────────────────────────────────────┘

x = encoder(history_slots)  → [batch, 44, 512]  (4 frames × 11 slots)

For each transformer layer i ∈ [0, 1, 2, 3]:
    │
    ├─ Get VLM guidance for this layer:
    │    old_i = vlm_old[:, i]     → [batch, 256, 3584]
    │    new_i = vlm_new[:, i]     → [batch, 16, 3584]
    │
    ├─ Project to predictor dimension:
    │    old_proj = proj_old(old_i) → [batch, 256, 512]
    │    new_proj = proj_new(new_i) → [batch, 16, 512]
    │
    ├─ Combine guidance:
    │    guidance = concat([old_proj, new_proj], dim=1) → [batch, 272, 512]
    │
    ├─ Generate FiLM parameters:
    │    scale, shift = mlp(guidance.mean(1)) → [batch, 512] each
    │
    ├─ Transform slots:
    │    x = transformer_block_i(x)           → [batch, 44, 512]
    │
    └─ Apply VLM guidance (FiLM):
         x = x * scale.unsqueeze(1) + shift.unsqueeze(1)
         │
         └─ Semantically modulates slot evolution at each layer!

     ↓

Output: predicted_slots [batch, 6, 11, 128]  ← Future 6 frames

ThinkJEPA's Innovation = DUAL-PATH + PYRAMID

  Dual-Path:
    vlm_old  → "What is happening now" (semantic understanding)
    vlm_new  → "What will happen next" (predictive reasoning)

  Pyramid:
    Layer 6  → Low-level features (edges, motion)
    Layer 12 → Mid-level features (objects, relations)
    Layer 18 → High-level features (scene structure)
    Layer 24 → Abstract features (intent, planning)

  Per-Layer FiLM:
    Each C-JEPA layer gets guidance from corresponding VLM depth
    → Hierarchical semantic modulation throughout prediction

This is why OLD structure failed:
  • Only had vlm_old (no predictive reasoning)
  • Averaged layers (no hierarchical guidance)
  • Wrong dimensions (incomplete features)

NEW structure enables TRUE ThinkJEPA behavior!
