1. HIERARCHICAL GUIDANCE
   ┌─────────────────────────────────────────────────────────────┐
   │ VLM Layer 0 → C-JEPA Layer 0: Low-level visual features    │
   │ VLM Layer 1 → C-JEPA Layer 1: Mid-level objects/motion     │
   │ VLM Layer 2 → C-JEPA Layer 2: High-level scene structure   │
   │ VLM Layer 3 → C-JEPA Layer 3: Abstract intent/planning     │
   └─────────────────────────────────────────────────────────────┘

   Each C-JEPA layer receives guidance at the CORRESPONDING semantic depth!

2. DUAL-PATH PER LAYER
   ┌─────────────────────────────────────────────────────────────┐
   │ For each layer:                                             │
   │   • vlm_old[i]: What VLM sees/understands (256 tokens)      │
   │   • vlm_new[i]: What VLM predicts will happen (16 tokens)   │
   │   • Combined: Input understanding + Reasoning (272 tokens)  │
   └─────────────────────────────────────────────────────────────┘

3. PER-LAYER FiLM
   ┌─────────────────────────────────────────────────────────────┐
   │ At each C-JEPA layer:                                       │
   │   1. Get guidance for this specific depth                   │
   │   2. Pool guidance tokens → [B, 512]                        │
   │   3. Generate scale & shift via MLP                         │
   │   4. Modulate slot features: x = x * (1+scale) + shift      │
   └─────────────────────────────────────────────────────────────┘

4. ZERO-INITIALIZED GATES
   ┌─────────────────────────────────────────────────────────────┐
   │ guidance_layer_scale = zeros(num_layers)                    │
   │                                                             │
   │ At initialization: gate = tanh(0) = 0                       │
   │ → VLM guidance has NO effect (model = vanilla C-JEPA)       │
   │                                                             │
   │ During training: gates gradually open                       │
   │ → VLM guidance smoothly increases influence                 │
   └─────────────────────────────────────────────────────────────┘
